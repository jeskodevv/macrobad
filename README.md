# macropad but its evil >:]

hackclub stardance macropad mission, but its evil. it has shortcuts for things i do frequently, and hyperfocus mode. 

for details about the design process or other information, check out the [stardance devlogs](https://stardance.hackclub.com/projects/25784). A local copy is available in [JOURNAL.md](https://github.com/jeskodevv/macrobad/blob/main/JOURNAL.md).

## WHAT IT HAS

- SEEEDUINO RP2040 MCU
- 5x SWITCHES
- 1X ROTARY KNOB
- 0.91' OLED SCREEN
- RGB LED
- awesome design inspired by original hackpad itself :D
